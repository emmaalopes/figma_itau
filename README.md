# 🎨 Identidade Visual - Banco Itaú

Este repositório contém a documentação e o guia de estilo (*Style Guide*) para a **Identidade Visual do Banco Itaú**, desenvolvido como modelo padronizado no **Figma** para ser utilizado ao longo de todos os trabalhos e projetos do curso.

---

## 📌 Visão Geral do Projeto

O objetivo deste projeto é recriar e estruturar o sistema de design (Design System / Style Guide) da marca Itaú no Figma, estabelecendo padrões visuais consistentes para:
- **Logo e Variações**
- **Paleta de Cores (Hexadecimal)**
- **Tipografia e Escala Tipográfica (*Font Scale*)**
- **Testes de Contraste e Acessibilidade**

---

## 🔤 Tipografia

- **Pesos Utilizados:** Light, Regular, Medium, Bold / Semibold

### Escala Tipográfica (*Font Scale*)
| Elemento | Tamanho (px) |
| :--- | :--- |
| **H1** | 40px |
| **H2** | 34px |
| **H3** | 28px |
| **H4** | 24px |
| **H5** | 18px |
| **Parágrafo** | 16px |
| **Small** | 14px |

---

## ♿ Contraste e Acessibilidade

O projeto inclui validações de contraste aplicadas sobre diferentes fundos e combinações de cores para garantir que os textos (desde a escala *Small 14px* até *H1 40px*) estejam legíveis e de acordo com as diretrizes da **WCAG**.
